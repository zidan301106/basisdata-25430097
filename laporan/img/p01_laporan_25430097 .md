## 4. Jawaban Titik Analisis

### Titik Analisis 1
**JAWABAN:** Label tombol pada XAMPP bertuliskan "MySQL", tetapi server yang sebenarnya berjalan adalah MariaDB 10.4.32. Dokumentasi MySQL masih relevan untuk perintah atau konsep SQL yang kompatibel dengan MariaDB. Namun, jika mengalami masalah yang berkaitan dengan konfigurasi, koneksi, vent, atau fitur khusus MariaDB, maka sebaiknya merujuk ke dokumentasi MariaDB. Hal ini penting agar solusi yang digunakan sesuai dengan server yang sebenarnya berjalan pada XAMPP.

### Titik Analisis 2
**JAWABAN:** Pesan Galat : `ERROR 1045 (28000): Access denied for user 'root'@'localhost' (using password: NO)`.

Bagian yang memberitahu tidak memberi password adalah `USING PASSWORD: NO`. `-p` artinya jika akun root sudah diberi password, maka tidak bisa masuk, menggunakan `USING PASSWORD: NO` artinya kamu tidak memasukkan password, ada lagi *Troubleshooting* `YES` artinya password yang diisi salah.

### Titik Analisis 3
**JAWABAN:** `information_schema` setiap tempat tersebut ada 123, sedangkan mysql ditandai dengan `ERROR 1044` Apa bedanya kode galat 1044 dengan 1045?

Perbedaan kode galat 1044 dengan 1045, adalah 1044 menandakan klien berhasil login, tapi tidak punya izin untuk mengakses database tertentu, dan 1045 berarti klien gagal melakukan login.

### Titik Analisis 4
**JAWABAN:** Mode cookie meminta pengguna mengetik password setiap kali masuk. Mengapa mode ini lebih aman daripada mode config yang menyimpan password dalam bentuk teks terkonfigurasi?

Mode config tidak menyimpan password di file config, sehingga harus memasukkan password, sedangkan mode config password disimpan dalam bentuk teks biasa. Jika berkas bocor, password dapat diketahui orang lain.

## 7. Pembahasan dan Kendala

### Konfigurasi pada SELECT @@sql_mode
Menjalankan `SELECT @@sql_mode` muncul hasil yang tidak ditampilkan modul. Muncul `NO_ZERO_IN_DATE,NO_ZERO_DATE,NO_ENGINE_SUBSTITUTION`.

Pada titik troubleshooting masalah 5, ditulis dijelaskan; Harus menambahkan strip pada `C:\xampp\mysql\bin\my.ini`.

### Kesalahan dalam mengetik username.
Kesalahan dalam mengetik username ketika ingin login root atau pun lainnya. Dengan contoh ingin memberi hak akses, dan terjadi kesalahan input dari ketiga menjadi keempat.

### Kesalahan dalam memahami konsep git dan github.
Awalnya terjadi kesalahan dalam memahami hubungan mengenai fungsi `git add`, `git commit`, dan `git push`, termasuk pada pembagian pada modul tersebut lalu di-push.

Setelah saya memahami materi dasar Git:
- `git add` memindahkan perubahan ke *staging area*.
- `git commit` mencatat perubahan sebagai *snapshot* lokal.
- `git push` mengirimkan perubahan tersebut ke repositori GitHub.
