## 2. Ringkasan Dasar Teori
MariaDB adalah sistem manajemen basis data relasional (RDBMS) berbasis arsitektur client-server. Pada lingkungan XAMPP, MariaDB bertindak sebagai server utama yang menyimpan data. Pengelolaan basis data dapat dilakukan melalui antarmuka perintah berbasis teks (CLI) menggunakan perintah SQL maupun antarmuka berbasis web seperti phpMyAdmin.
